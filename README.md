# 🏯 Jogo de Heróis

## 📜 Sobre o Projeto
Este projeto foi desenvolvido para representar um sistema de criação de heróis em um jogo de aventura. O usuário pode definir o nome, idade e classe do herói, e então visualizar sua ação de ataque personalizada com base no tipo escolhido.

## 🚀 Tecnologias Utilizadas
- **HTML**: Estruturação da interface gráfica.
- **CSS**: Estilização da página para uma experiência visual agradável.
- **JavaScript**: Lógica de criação do herói e definição do ataque.

## 🎮 Funcionalidades
- O usuário insere o nome, idade e tipo do herói.
- Cada tipo de herói possui um ataque único.
- A ação do ataque é exibida de forma interativa na interface.
